## Creating a Pull Request

Click the link for your branch type to open a pre-filled PR form:

| Branch type | Create PR |
|---|---|
| `feature/*` | [Open feature PR](https://github.com/Chamana/SampleTestJenkinsProject/compare/master...HEAD?template=feature.md) |
| `fix/*` / `bugfix/*` | [Open bugfix PR](https://github.com/Chamana/SampleTestJenkinsProject/compare/master...HEAD?template=bugfix.md) |
| `hotfix/*` | [Open hotfix PR](https://github.com/Chamana/SampleTestJenkinsProject/compare/master...HEAD?template=hotfix.md) |
| `release/*` | [Open release PR](https://github.com/Chamana/SampleTestJenkinsProject/compare/master...HEAD?template=release.md) |
| `chore/*` | [Open chore PR](https://github.com/Chamana/SampleTestJenkinsProject/compare/master...HEAD?template=chore.md) |
